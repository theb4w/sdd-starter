# Playbook: investigation

**Family:** Understand
**Intent:** How / why / are we sure / blast radius
**Profile:** `observe`
**Not when:** the user wants a change — answer, then match the catalog again.
**Basis:** spec-kit analyze (read-only). Cite artifacts; no patch in the same pass.

## Steps

1. **Step 0** if the repo already has `SDD/` (citations). Do not fill a fake BRIEF.
2. Restate the question as something evidence can answer. Include blast radius if the user asked what else breaks.
3. Search code, `SDD/`, tests, git. Prefer primary files.
4. Answer with paths. Separate fact / inference / unknown.
5. Empirical fork → `prototype.md`.
6. No production edits.

## Reply

Answer, citations, unknowns, next catalog row if any.
