# Playbook: investigation

**Gate profile:** `observe`
**When:** read-only how/why/are we sure.
**Not when:** the user wants a change — answer, then pick a build playbook.

## Steps

1. Ensure `SDD/` if the repo already uses it (for citations). Do not create a filled BRIEF.
2. Restate the question as something evidence can answer.
3. Search code, `SDD/` artifacts, tests. Prefer primary files.
4. Answer with paths. Separate fact / inference / unknown.
5. Empirical fork → offer `prototype.md`.
6. No production edits.

## Reply

Answer, citations, unknowns, next playbook if any.
