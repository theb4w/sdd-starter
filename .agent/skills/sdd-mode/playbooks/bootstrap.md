# Playbook: bootstrap

**Family:** Arrive
**Intent:** New project, I know the brief
**Profile:** `agentic`
**Not when:** no brief and unknown domain → `discover.md`.
**Basis:** spec-kit 0-to-1 + constitution + specify. Human owns intent (BRIEF). HOW is agentic unless promoted to `full`.
**Skills:** `sdd-tdd`, `review.md`

Promote to `full` if WHAT is unclear, schema/service/compliance, or the user asked.

## Steps

1. **Step 0** of `sdd-mode` (ensure `SDD/`). BRIEF §1–§6 filled, or fill with the human before SPECs.
2. Read BRIEF, `SDD/AGENTS.md`, `catalog.md` (this row), SKILL gate profiles. Do not dump `workflow.md`.
3. Summarize stage, stack constraints, core module.
4. Fill `SDD/AGENTS.md` from the brief, including **`Smoke:`** (command or URL). Do not invent an open stack. Placeholder `Smoke:` means later packages cannot be accepted.
5. Draft `SDD/architecture.md`. Fill `SDD/INDEX.md`.
6. Write `SDD/modules/SPEC_<CORE>.md`. Product CLARIFY → **STOP**.
7. ADRs for stack trade-offs (URL each).
8. Write PLAN + TASKS. `full`: **STOP G1** then **STOP G2**. `agentic`: continue.
9. IMPLEMENT first phase + `sdd-tdd`.
10. `review.md` + G3.
11. **Package.** Branch. `handover.md`.

## Reply

Stage, core module, profile, package or BRIEF/CLARIFY stop.
