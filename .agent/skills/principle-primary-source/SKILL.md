# Primary source

A technical choice with two or more viable options needs an ADR. Each option needs a primary-source URL (docs of the tool, RFC, spec, vendor page). “Best practice” without a URL is not a justification.

If you cannot find a URL, say so and stop. Do not invent citations.

**Source:** `SDD/AGENTS.md` regra 2; `sdd-mode/templates/adr.md`.
