# Workflow: SDD Implement

Ponteiro. Depois de GATE 1 e GATE 2 (quando o perfil os inclui):

- unidade já aprovada → `.agent/skills/sdd-mode/playbooks/tdd-implement.md`
- skill de loop → `.agent/skills/sdd-tdd/SKILL.md`
- feature / bug / story / refactor → o playbook pai ainda dono de G3 e G4

Não implementar sem o contrato do playbook. Uma TASK por vez.
