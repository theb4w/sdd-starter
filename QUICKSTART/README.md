# QUICKSTART

Escolha um guia pelo tipo de trabalho, nao pela ferramenta usada.

| Se voce quer... | Leia |
|---|---|
| Comecar projeto novo | `greenfield.md` |
| Entrar em repo que ja usa SDD | `cloned-repo.md` |
| Adotar SDD em projeto existente | `brownfield.md` |
| Corrigir um bug | `bug-fix.md` |
| Fazer feature pequena | `small-feature.md` |
| Fazer feature media | `medium-feature.md` |
| Fazer feature grande ou multi-fase | `large-feature.md` |
| Refatorar | `refactor.md` |

Cada quickstart indica quais artefatos criar, quais gates respeitar e quando o
fluxo pode ser enxuto.
