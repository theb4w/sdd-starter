# Tooling opcional

O workflow SDD do `sdd-starter` nao depende desta pasta.

Use estes materiais apenas quando o projeto escolher uma ferramenta que se
beneficie de arquivos proprios de configuracao ou instrucao. Eles adaptam a
execucao ao ambiente escolhido; nao substituem `docs/SDD_WORKFLOW.md`, specs,
plans, tasks ou handovers.

| Pasta | Conteudo |
|---|---|
| `antigravity/` | Exemplo de `GEMINI.md` para projetos que adotam Antigravity |
| `cursor/` | Rules opcionais para projetos que adotam Cursor |

Ao copiar qualquer arquivo desta pasta para um projeto real:

1. leia o arquivo antes;
2. remova placeholders;
3. confirme que ele nao contradiz o workflow SDD do projeto;
4. registre no projeto que aquele tooling foi adotado.
