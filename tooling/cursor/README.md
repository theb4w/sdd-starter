# Cursor

Rules opcionais para projetos que adotam Cursor junto com SDD.

Copie `tooling/cursor/.cursor/` para a raiz do projeto apenas quando quiser que
Cursor carregue essas regras automaticamente. As rules apontam para
`.agent/skills/sdd-mode/`; nao redefinem o metodo.

Revise os limites e gates (ADR-002) antes de adotar.
