# Project Brief — sdd-starter

**Data:** 2026-08-26
**Versão:** 2.0

## 1. Objetivo

Skill pack de Spec-Driven Development: o agente invoca `sdd-mode`, escolhe um playbook e gera `SDD/` com o processo do produto.

## 2. Fora do MVP

- ❌ Plugin Cursor como artefato principal
- ❌ Autonomia tipo pstack (never-block, merge overnight)
- ❌ Stack de referência obrigatória
- ❌ CI/scripts de bootstrap neste repo

## 3. Módulos

- **SDD_MODE**: roteador, playbooks, principles, geração de `SDD/`
